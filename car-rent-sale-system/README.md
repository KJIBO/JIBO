# DriveHub - Car Rental and Sales Website

A PHP + MySQL starter project for a car rental and car selling business.

## Features
- Public homepage
- Cars for rent and cars for sale pages
- Car details page
- Booking form
- Purchase inquiry form
- Contact form
- Admin login and dashboard
- Manage cars (add, edit, delete)
- View bookings and sales inquiries
- Prepared statements and session auth

## How to Run on XAMPP
1. Copy the folder to `C:\xampp\htdocs\car-rent-sale-system`
2. Start Apache and MySQL in XAMPP
3. Import `database.sql` into phpMyAdmin
4. Open `http://localhost/car-rent-sale-system/`
5. Admin login:
   - Email: `admin@drivehub.com`
   - Password: `admin123`
